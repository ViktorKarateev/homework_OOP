# Homework OOP

##  Описание  
Проект по изучению объектно-ориентированного программирования (OOP) на Python.  
Добавлены классы `Product` и `Category` с различными методами и функционалом.

---

##  Функциональность проекта

### **1. Класс `Product`**
Класс `Product` отвечает за представление товаров и включает в себя:
- Название товара (`name`)  
- Описание (`description`)  
- Цена (`price`)  
- Количество на складе (`quantity`)  

Теперь в классе `Product` добавлены:
- **Приватный атрибут `__price`**
- **Геттер `@property price`** → возвращает цену товара.  
- **Сеттер `@price.setter`** → защищает цену от отрицательных значений.  
- **Метод `new_product()`** → создаёт новый продукт из словаря, проверяет дубликаты.  
- **Метод `__add__()`** → складывает только товары одного типа (`type(self) is type(other)`), иначе `TypeError`.
- **Обработка исключения при создании товара с нулевым количеством** → выбрасывается `ValueError`.

---

### **2. Класс `Category`**
Класс `Category` отвечает за категории товаров и включает:
- Название категории (`name`)  
- Описание (`description`)  
- Список товаров (`products`) — теперь приватный (`__products`)  

Теперь в классе `Category` добавлены:
- **Метод `add_product()`** → добавляет товар только если это `Product` или его наследник (`isinstance`).  
- **Геттер `@property products`** → возвращает отформатированный список товаров.  
- **Метод `middle_price()`** → возвращает среднюю цену товаров в категории. Если товаров нет — возвращает `0`.

---

##  Новая функциональность (последние доработки)

### **1. Абстрактный класс `BaseProduct`**
- Реализован с использованием `ABC` и `@abstractmethod`.
- Все товары (`Product`, `Smartphone`, `LawnGrass`) наследуют от него.
- Обязывает реализовать метод `get_info()`.

### **2. Миксин `LoggingMixin`**
- При создании товара печатает сообщение о создании экземпляра с параметрами.
- Наследуется в цепочке через `Product`.

---

##  Наследники класса Product

###  `Smartphone`
Дополнительные атрибуты:
- `efficiency`, `model`, `memory`, `color`
- Метод `get_info()` возвращает расширенное описание смартфона.

###  `LawnGrass`
Дополнительные атрибуты:
- `country`, `germination_period`, `color`
- Метод `get_info()` возвращает описание травы.

##  Тесты
- Используется `pytest`
- Проверяется:
  - Создание продуктов и категорий
  - Сложение одинаковых товаров и `TypeError` при попытке сложить разные
  - Геттер/сеттер цены
  - Метод `middle_price()`
  - Создание наследников `Smartphone`, `LawnGrass`
  - Ошибка при создании продукта с нулевым количеством (`ValueError`)

---

##  Загрузка данных
- Реализована функция `load_categories_from_json()` в `utils.py`
- Поддерживается загрузка из файла `products.json` с преобразованием в объекты `Category` и `Product`.
